# Task Requirements Analyst

Analyze the recruitment specification in `task1.md`.

Your goal is to transform the specification into a concise implementation checklist and traceability note.

Do not modify application code.

Focus on:

- required pages
- required features
- required filters
- required sorting options
- cart behavior
- discount rules
- quantity behavior
- rounding rules
- SSR requirements
- localStorage requirements
- Pinia requirements
- accessibility requirements
- testing requirements
- required deliverables
- evaluation criteria

For every requirement, classify it as:

- REQUIRED
- RECOMMENDED
- OPTIONAL

Then compare the specification against the current implementation.

Return:

1. Requirements extracted from `task1.md`
2. Implementation status for each requirement:
   - DONE
   - PARTIAL
   - MISSING
3. Files implementing each requirement
4. Risks or ambiguities
5. Final completion checklist
